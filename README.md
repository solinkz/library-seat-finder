# Group 1 — Library seats

This repository contains the Group 1 library seat example from the IFI7386 Interactive Systems course. It is a self-contained Arduino and Node.js prototype for reporting the status of two pressure-sensor seats and displaying the library layout.

## Contents

- `host/` — Node.js server, browser interface, optional simulator and tests.
- `library/` — Arduino sketch that sends sensor readings over Wi-Fi.
- `library_serial/` — serial-only Arduino sketch for sensor calibration.

See the source example documentation in `group-1-library/README.md` for setup instructions.
